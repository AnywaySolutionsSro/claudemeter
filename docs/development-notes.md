# Development notes

A record of how ClaudeMeter was built and the decisions behind it, so the reasoning isn't lost.

## Goal

A low-footprint macOS menu-bar utility showing Claude subscription usage — percent remaining and
time until reset — that a non-technical friend can install.

## Key decisions (and how they evolved)

1. **Data source: real, not estimated.** First sketch parsed local `~/.claude/projects/*.jsonl`
   token counts against a static plan budget (the `ccusage` approach). Replaced with the **real
   server-side numbers** from `GET /api/oauth/usage` — the same data `/usage` shows. No plan
   configuration. Endpoint + schema were recovered by `strings`-grepping the Claude Code binary
   (see [anthropic-endpoints.md](anthropic-endpoints.md)).

2. **Native Swift menu-bar app**, built with **SwiftPM only** (no Xcode project). `build.sh`
   assembles the `.app` bundle (Info.plist with `LSUIElement`), ad-hoc signs for local use, or
   Developer ID signs + notarizes for distribution.

3. **Auth: self-owned, not Claude Code's token.** Originally read Claude Code's
   `Claude Code-credentials` Keychain item. That caused constant macOS password prompts (the
   ACL is tied to the code signature, which changes on every ad-hoc rebuild) and risked
   logging Claude Code out via refresh-token rotation. Switched to ClaudeMeter doing its **own**
   OAuth login (PKCE) and storing the token in its **own** Keychain item. Independent and
   prompt-free once stably signed.

4. **One-click login.** The binary revealed the OAuth client allows a loopback redirect
   (`http://localhost:<port>/callback`). So `LoopbackCallbackServer` captures the redirect
   automatically — the user only approves in the browser, no code pasting. Manual paste remains
   as a fallback.

5. **Branding.** Menu-bar pill with a Claude-orange (`#D97757`) rounded border; a gauge app icon
   generated by `Resources/make_icon.swift` → `iconutil`.

## Bugs found and fixed during the build

- **Reset time missing.** `resets_at` is an ISO-8601 **string** (microsecond precision), not the
  epoch number the CLI doc comment claimed. Added `ISODate` (strips fractional seconds; the
  decoder accepts both forms).
- **Dropdown wouldn't close on outside click.** A background agent's `.transient` popover never
  becomes key, so AppKit's auto-dismiss doesn't fire. Added a global mouse-down monitor.
- **HTTP 429.** Frequent reinstalls + refresh-on-every-open hit the rate limit. Added throttling
  (≤1 call/30 s), `Retry-After` backoff, and an on-disk cache shown instantly on launch.
- **Cmd+V didn't work** in the login text field — agent apps have no menu bar. Added a minimal
  Edit menu (`installEditMenu`).
- **Blank/black pill on cold launch** — the label only redrew on a 30 s timer. Now redraws on
  `UsageStore`/`AuthModel` `objectWillChange` (Combine) and once post-launch, resolving colors
  against the menu bar's `effectiveAppearance`.

## Footprint choices

- Poll every 5 min (tiny JSON); instant refresh on popover-open and wake.
- Per-second countdown ticker exists only while the dropdown is open.
- No Dock icon / window (`LSUIElement` + `.accessory`).
- Login item via `SMAppService` (modern API; appears in System Settings → Login Items).

## Testing

Pure logic lives in `ClaudeMeterCore` and is unit-tested (decoder incl. the real ISO-8601 shape,
PKCE against the RFC 7636 vector, formatting, bucket math). `swift test` should stay green.
